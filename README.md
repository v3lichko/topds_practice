A small research project for **Yandex Practice** (ITMO Software Engineering track).  
We collect and analyze data from three large open-source repositories:

- **Jupyter Notebook** — `jupyter/notebook`
- **JupyterLab** — `jupyterlab/jupyterlab`
- **Visual Studio Code** — `microsoft/vscode`

The goal is to practice **data collection, cleaning, exploratory analysis, and reporting** on real OSS ecosystems.

---

## 🎯 Objectives

- Automatically **collect repository metadata** (stars, forks, issues, activity, contributors, releases, etc.)
- Build a **clean dataset** for analysis
- Run **EDA + comparisons** between projects
- Produce **visualizations** and a short **report** with insights

---

## 📦 Data We Analyze (example)

Depending on the task version, we may include:

- Repo metadata: stars, forks, open issues, watchers, default branch
- Activity: commits over time, releases timeline, PR/issue dynamics
- Community: contributors count, top contributors, response times
- Code stats (optional): language distribution, file structure
